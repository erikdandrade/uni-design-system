### Overview

Radio buttons are user interface controls that allow users to select a single option from a set of mutually exclusive choices. Radio buttons are typically used when the user needs to select one option from a group, and the options are related or dependent on each other.

### Principles

1. **Mutual Exclusivity**: Only one option from a set can be selected.

1. **Visual Distinction**: Radio buttons should have a distinct appearance.
