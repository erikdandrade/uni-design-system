
# Usage

---

### Main Usage

Allowing users to select a single option from a set of mutually exclusive choices when the options are related or dependent on each other.

  
![Do](https://studio-assets.supernova.io/design-systems/145982/29d19da2-5f49-4808-bef9-106456b081d0.png)  
Do, Allow the user to select only one option  
  
![Don't](https://studio-assets.supernova.io/design-systems/145982/41c86557-9132-4f4d-a2b4-4493dfc24ad3.png)  
Don't, Don't allow the user to select more than one option  
  


If the users need to be able to refrain from selecting one option. Provide an option labeled as “None’.
