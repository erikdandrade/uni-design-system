
# Usage

---

### Main Usage

Use Sliders when users need to **select a value or range within defined limits**, especially when the exact value is less important than the relative position or range.

Do  
![Do](https://studio-assets.supernova.io/design-systems/145982/6fa4a0f8-1946-4111-ba08-7bf82557186d.png)  
Always show selected value  
Don't  
![Don't](https://studio-assets.supernova.io/design-systems/145982/718ab4c7-8b83-4538-9bd8-f90bbd415074.png)  
Don’t hide min or max values.
