
# Usage

---

### Main Usage

Checkboxes are versatile controls that can be used in various contexts where users need to make selections. They are particularly useful when multiple options can be selected, or when an option needs to be toggled on or off.

Allow users to select more than one option from a list when it's appropriate, Avoid using checkboxes when only one option can be selected.

  
![Do](https://studio-assets.supernova.io/design-systems/145982/62512952-686b-4a54-b9b9-df3e1909a7da.png)  
Do, Use checkboxes for multiple selections  
  
![Don't](https://studio-assets.supernova.io/design-systems/145982/2056e1ac-80c5-4c6c-8438-e875a7734249.png)  
Don't, Use checkboxes for single selections  
  


Ensure each checkbox has a clear and descriptive label that accurately reflects the option or action. Avoid labels that don’t clearly describe what the checkbox does.

  
![Do](https://studio-assets.supernova.io/design-systems/145982/c857229b-5259-448d-b5a4-d76ce9de69a2.png)  
Do, Label checkboxes clearly  
  
![Don't](https://studio-assets.supernova.io/design-systems/145982/793968f7-664c-4701-9801-22e4bbc23fae.png)  
Don't, Use unclear or vague labels  
  


When presenting a set of related options, place the checkboxes close to each other within a defined group.

  
![Do](https://studio-assets.supernova.io/design-systems/145982/1bd2cc01-c77c-4a93-a3d8-43f40a9a6965.png)  
Do, Group related checkboxes together  
  
![Don't](https://studio-assets.supernova.io/design-systems/145982/5f66d8aa-9e50-4876-be39-a824d0922036.png)  
Don't, Scatter-related checkboxes across the interface  
  


### **Consider adding ‘Select all’ option**

When presenting a list of multiple checkboxes, especially in long lists, consider adding a ‘Select All’ checkbox at the top of the group. This allows users to quickly select or deselect all options with a single action, enhancing usability and efficiency.

  
![Do](https://studio-assets.supernova.io/design-systems/145982/aaf963a6-6e72-4adb-996a-d99cf8a9c1a2.png)  
Do, Checkboxes let users select one or more options from a list. A parent checkbox allows for easy selection or deselection of all items.  
  


When presenting checkboxes, list them vertically to improve readability and ensure a clear, organized layout. Vertical alignment makes it easier for users to scan and select options, particularly in forms or lists with multiple items.

  
![Do](https://studio-assets.supernova.io/design-systems/145982/d6407b3b-10fa-483b-915a-c1222b6a18e0.png)  
Do, List vertically   
  
![Don't](https://studio-assets.supernova.io/design-systems/145982/7397f131-af4b-4797-a384-7d2ad0198a1e.png)  
Don't, List horizontally
