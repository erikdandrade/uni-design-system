
# Percentage

---

Percentage numbers and calculation is done

  
| Column 1 | Column 2 | Column 3 | Column 4 | Column 5 |  
| --- | --- | --- | --- | --- |  
|  | &num; to format | Standard | Short | Behavior |  
| **< 1000** |  | 1% &hyphen; 900% | 1% &hyphen; 900% | Use integer number |  
| **< 100,000** |  | 100,400% &hyphen; 99,999% | 1.4K% &hyphen; 99.9K% | Use of one decimal |  
| **< 1,000,000** |  | 100,000% &hyphen; 999,999% | 100K% &hyphen; 999K% | Round to the closest thousand |  
| **< 100,000,000** |  | 1,000,000% &hyphen; 99,999,999% | 1.4M% &hyphen; 99.6M% | Use of one decimal |  
| **>= 100,000,000** |  | 100,000,000% &hyphen; 9,999,999,999% | 100M% &hyphen; 9,000M% | Round to the closest million |
