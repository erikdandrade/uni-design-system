## Overview

Spacing is a fundamental aspect of the UNI design system, crucial for creating consistent, visually appealing, and user&hyphen;friendly interfaces. This guide outlines our approach to spacing, including our scale, usage guidelines, and best practices.

## Spacing Scale

UNI uses a consistent spacing scale based on 4px increments. This scale provides flexibility while maintaining harmony across all components and layouts.

Examples:

  
| Column 1 | Column 2 | Column 3 |  
| --- | --- | --- |  
| Token | Value | Usage |  
| `$space&hyphen;0` | 0px | No spacing |  
| `$space&hyphen;025` | 2px | Minimal spacing, icon padding |  
| `$space&hyphen;050` | 4px |  |  
| `$space&hyphen;100` | 8px |  |

## Usage Guidelines

### 1. Component Spacing

- Use consistent spacing within components to ensure visual harmony.

- Apply appropriate spacing between interactive elements to enhance usability.

- Maintain consistent padding within containers like cards, modals, and panels.

### 2. Layout Spacing

- Use larger spacing values to separate major sections of a page or application.

- Implement a consistent vertical rhythm using the spacing scale.

- Adjust spacing based on screen size and device type for responsive designs.

### 3. Hierarchy and Grouping

- Use spacing to create visual hierarchies and group related elements.

- Apply tighter spacing for closely related items and wider spacing for distinct groups.

## Best Practices

1. **Consistency**: Stick to the defined spacing scale to maintain a cohesive look across the entire system.

1. **Accessibility**: Ensure sufficient spacing between interactive elements for easy tapping on touch devices (minimum 44x44px touch target).

1. **Whitespace**: Don't be afraid of whitespace. It helps improve readability and focus.

1. **Nesting**: When nesting components, consider the cumulative effect of spacing to avoid unintended gaps or cramping.

1. **Flexibility**: While consistency is key, allow for exceptions when necessary to address specific design needs.

1. **Documentation**: Always document any custom spacing used outside the standard scale, explaining the rationale.
