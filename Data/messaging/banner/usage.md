
# Usage

---

### Main Usage

Use Banners to deliver **persistent or contextual information** that users should notice before continuing, such as system states, warnings, announcements, or guidance related to the current page or task.



Do  
![Do](https://studio-assets.supernova.io/design-systems/145982/07b38f1a-fd4b-488d-bf17-53255aca71ab.png)  
Use to provide inline contextual guidance, warnings, or system states.  
Don't  
![Don't](https://studio-assets.supernova.io/design-systems/145982/774e94da-a67e-4a98-a3fc-a28b65f75d9b.png)  
Don’t use for short&hyphen;lived feedback (use Snackbar instead).
