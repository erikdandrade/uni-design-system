
# Usage

---

### Primary Button

Use one primary button per context to help users do something specific, move forward in a flow, acknowledge and dismiss, or complete a task.

Do  
![Do](https://studio-assets.supernova.io/design-systems/145982/1f171183-8ca8-4720-8a47-bb662c30798c.png)  
Use for quick, primary contextual actions such as “send” or “download.  
Do  
![Do](https://studio-assets.supernova.io/design-systems/145982/9a7561cd-416b-4160-b7ee-44a5225d7552.png)  
Use multiple secondary icon buttons for related actions.  
Don't  
![Don't](https://studio-assets.supernova.io/design-systems/145982/903014d1-b7c6-4338-a826-af857cde7386.png)  
Don’t replace text buttons with icons for primary calls to action.
