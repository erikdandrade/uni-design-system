
# Usage

---

### Main Usage

Tags are used to label or categorize items simply. They are non‐interactive markers to indicate status, group content, or annotate items with contextual information without requiring user action.

Do  
![Do](https://studio-assets.supernova.io/design-systems/145982/177dd168-b11e-4277-a22f-d26c9c28a623.png)  
Keep the tag text short so its purpose is immediately clear.  
Don't  
![Don't](https://studio-assets.supernova.io/design-systems/145982/32658fd4-1537-49f6-8108-cf8941f87eb1.png)  
Don't use much text or more than one icon per tag.

### Style & Interactivity

Don't  
![Don't](https://studio-assets.supernova.io/design-systems/145982/8fe80c97-f57a-4518-a11a-6678cf71fa67.png)  
Avoid ornate or overly stylized elements that distract from the content.   
Caution  
![Caution](https://studio-assets.supernova.io/design-systems/145982/11629c37-2b91-4419-b144-d1cb7ca505ac.png)  
Keep tags non&hyphen;interactive—if interaction is required, use a chip instead.
