Tag Overview  


### Overview

A **Tag** is a simple, non‐interactive UI element that labels or categorizes content. It typically consists of an icon (or logo) and a brief text within a visually defined container. Tags are ideal for highlighting status, categories, or attributes without drawing excessive attention.

### Principles

1. **Clarity: **The text and icon should immediately convey the tag’s meaning. Use legible fonts and intuitive icons.

1. **Simplicity: **Tags should be minimalistic. Avoid excessive ornamentation that might distract from the content.

1. **Scalability: **Design tags to handle varying text lengths and icon sizes without losing visual balance.
