### Main Usage

The Tabs component is commonly used in scenarios where an application or website has distinct sections or views that users need to navigate between, such as in web applications, dashboards, or multi-step forms.


  
![Do](/images/f5979148-13bd-446e-b5bf-2cd878989412.png)  
Do, Use concise and descriptive labels for each tab, making it obvious to users what type of content they represent.  
  
![Don't](/images/46584b67-ba6d-48e0-87c8-1b1f2263f365.png)  
Don't, Avoid using ambiguous or confusing labels for the tabs, as this can lead to user confusion and frustration.  
  


  
![Do](/images/e59ae546-6bc9-49ec-aa2b-058372d2c4e6.png)  
Do, Use short labels to ensure they're visible.  
  
![Don't](/images/8370e8bd-7d5f-45f9-901c-d42042a7cc7b.png)  
Don't, Longer tab label shouldn't be truncated.  
  


### Grouping

  
![Do](/images/0759a796-abc2-4b3d-92d5-a03d63882350.png)  
Do, Group related content or sections together under a single tab, following a logical structure and hierarchy.  
  
![Don't](/images/97c4669e-ddda-4aee-a67b-4c71267fad0a.png)  
Don't, Group unrelated content or sections together under a single tab to prevent confusion and frustration.
