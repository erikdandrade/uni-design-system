Percentage numbers and calculation is done

  
| Column 1 | Column 2 | Column 3 | Column 4 | Column 5 |  
| --- | --- | --- | --- | --- |  
|  | &num; to format | Standard | Short | Behavior |  
| **< 1000** |  | 1% - 900% | 1% - 900% | Use integer number |  
| **< 100,000** |  | 100,400% - 99,999% | 1.4K% - 99.9K% | Use of one decimal |  
| **< 1,000,000** |  | 100,000% - 999,999% | 100K% - 999K% | Round to the closest thousand |  
| **< 100,000,000** |  | 1,000,000% - 99,999,999% | 1.4M% - 99.6M% | Use of one decimal |  
| **>= 100,000,000** |  | 100,000,000% - 9,999,999,999% | 100M% - 9,000M% | Round to the closest million |
