Do  
![Do](/images/1cd4acca-1d5b-4e09-8263-4824ca44ec58.png)  
Use Link Buttons for **inline navigation** or **secondary actions** like “Learn more” or “View details,” including external links for more info.  
Don't  
![Don't](/images/67634fa5-45ac-497a-8ae4-c3f8843f86ef.png)  
Avoid using them as **primary CTAs** — they lack the visual emphasis needed for main actions.
