### Overview

A **Chip** is an interactive UI element typically used to represent selected items, filters, or user inputs. A chip usually contains mandatory text, an optional icon for additional context, and a close (remove) button to allow users to deselect or remove it. Chips are especially useful when multiple selections are possible.

### Principles

1. **Interactivity: **Provide clear visual feedback (hover, active, pressed states) so users understand that chips are actionable.

1. **Clarity: **The chip’s label must be concise and legible, and any accompanying icon should reinforce the intended meaning.

1. **Removability: **Close button should always be visible and easy to interact with.
