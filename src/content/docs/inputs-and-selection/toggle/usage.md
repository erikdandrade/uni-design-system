### Main Usage

Allowing users to switch between two mutually exclusive states or options, typically for enabling or disabling specific features or settings, or for toggling between different modes or views.

Toggle immediately activates a state, not performing a single action. Don’t use a toggle to take an action like downloading an app, since turning off the switch wouldn’t uninstall the app. Consider a button for that instead.

Toggles work independently. If you have a set of toggles, toggling one switch should not control other switches. 
Consider using a checkbox group if you need a "select all" pattern.
