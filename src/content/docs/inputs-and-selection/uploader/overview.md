## 1. Uploader Button

  
![Uploader Button Overview](/images/98a1f9e3-1221-4fdd-90a0-0837fa50f673.png)  
Uploader Button Overview  


### Overview

A button that opens the system file picker to upload files, images, or videos.

### Principles

1. **Feedback:** The selected value or range should always be visible.

1. **Boundaries:** Minimum and maximum values must be clearly defined.

## 2. Uploader Dropzone

  
![Uploader Dropzone Overview](/images/0d4e2558-b451-47a9-b1d0-81f44d866909.png)  
Uploader Dropzone Overview  


### Overview

A clickable area that opens the system file picker, designed to emphasize uploading as a primary action.

### Principles

1. **Affordance:** The dropzone should visually communicate that it is interactive.

1. **Emphasis:** The design should signal that uploading is a primary task.

## 3. Uploader Image

  
![Uploader Image Overview](/images/d0aca334-8623-4e1b-8ec0-ed89fefb97bf.png)  
Uploader Image Overview  


### Overview

A compact image-only upload component with inline validation and error messaging.

### Principles

1. **Focus:** The component should support image uploads only.

1. **Compactness:** Design should remain minimal and space-efficient.

1. **Validation:** Errors should be shown immediately and in-line.

1. **Guidance:** Image requirements should be clearly communicated.

## 4. Uploader File

  
![Uploader File Overview](/images/6092c1c5-e511-4b0a-af63-46ef46bda0f2.png)  
Uploader File Overview  


### Overview

Displays an uploaded file with type icon, file name, size, and delete action.

### Principles

1. **Recognition:** File type should be immediately identifiable through icon and name.

1. **Transparency:** File size and details should be clearly visible.

1. **Control:** Users should be able to remove files easily.
