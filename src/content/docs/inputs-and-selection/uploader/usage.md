### Main Usage

Use Sliders when users need to **select a value or range within defined limits**, especially when the exact value is less important than the relative position or range.

Caution  
![Caution](/images/c9ff7d3d-700e-460a-b9cf-48c6a75d0c57.png)  
Unexpected file restrictions can frustrate users.

Do  
![Do](/images/2fce9cfc-08d7-40bf-ba6d-e0214426edc3.png)  
Use when uploading is a primary task. Clearly communicate supported file types and limits. Make the entire area clickable.  
Don't  
![Don't](/images/038d9f26-6e64-490f-aa40-2972aebba055.png)  
Don’t use multiple dropzones for the same purpose.

Do  
![Do](/images/c28bc0b3-03db-413e-9e65-56433056b75b.png)  
Use for image-only uploads such as avatars or covers.  
Do  
![Do](/images/20626af3-c531-468f-9cbe-169ccc4ba540.png)  
Validate image type and size immediately. Show clear error messages inline.  
Caution  
![Caution](/images/f9c9b4fa-13cf-401d-84ca-22896306e3ac.png)  
Consider preview and replace behaviors carefully.

Do  
![Do](/images/892e9ca5-a440-4964-8339-491b8ec5af68.png)  
Display file name, size, and type clearly and provide a visible delete action.
