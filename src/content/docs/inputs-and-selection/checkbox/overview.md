### Overview

A checkbox is a user interface control that allows users to select one or multiple options from a set. Checkboxes are commonly used in forms, filters, and settings where users can make multiple selections or toggle individual options on or off.

### Principles

1. **Multiple Selection**: Checkboxes allow users to select more than one option from a group, unlike radio buttons, which are limited to a single selection.

1. **Clear States**: Each checkbox should clearly indicate whether an option is selected (checked) or not (unchecked). An optional indeterminate state can be used to represent a mixed selection.

1. **Independent Actions**: Selecting or deselecting a checkbox should not immediately trigger an action but instead allow users to review their choices before submission.

1. **Accessibility**: Ensure that checkboxes are easily navigable via keyboard and screen readers, with clear labels and focus states.
