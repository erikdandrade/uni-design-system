### Main Usage

Use Snackbars to provide **immediate, contextual feedback** in response to a user action, such as confirming success, surfacing errors, or sharing brief system updates, without interrupting the user’s workflow.

Do  
![Do](/images/7e8cba1f-80e0-46d2-9d80-8a87aa741c24.png)  
Use to confirm the result of a user action (success, error, info).  
Don't  
![Don't](/images/887a230f-37fe-40f4-8045-d2c1978b2464.png)  
Don't use for critical or emergency messaging  
Caution  
![Caution](/images/2cbd55ec-3d72-4bad-b79d-766a12d3b5fa.png)  
Ensure snackbars don’t obscure important UI elements.
