### Main Usage

Use Separators to **visually divide content into logical sections** when spacing alone isn’t enough to communicate structure or relationships between content blocks.

Don't  
![Don't](/images/3a336807-f7ae-4810-9f93-8fe99c94c17e.png)  
Don’t replace proper spacing with separators.
